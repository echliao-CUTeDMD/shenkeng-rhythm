# 深坑節奏祭：四寶上桌！

以完整遊戲規則書 v3.0 改編的純 HTML / CSS / JavaScript 節奏遊戲。
不需安裝套件、不需後端、不需 API 金鑰。所有素材以相對路徑載入，支援 GitHub Pages 子目錄。

## 開始玩
雙擊 index.html 即可遊玩。建議使用新版 Chrome、Edge 或 Safari。點擊開始後才會啟用瀏覽器音效。

- 單人數位挑戰：A 豆腐、S 茶葉、D 長按竹筍、J＋K 黑豬。手機直接點節奏墊，黑豬需兩指同時操作。
- 桌遊主持模式：3–6 人使用實體節奏墊。電腦提供節拍，由當單主持人輸入全隊錯誤數；每單輪替主持人。
- 三張暖身、九張訂單、一般／加急選擇、正式前練習、一次重試、自動人氣與最終稱號。
- 所有速度的數位版免費練習均為一遍 8 拍；50 BPM 為速度調整，並未完整實作規則書第 13 頁的教學變體。
- 切到其他頁面或視窗失去焦點，當次演奏作廢，不扣重試。
- 沒有線上多人連線，沒有帳號，重新整理會清除本局。

## 上傳 GitHub Pages
1. 建立 GitHub repository。
2. 解壓縮，將 **index.html、style.css、game.js、assets 資料夾、.nojekyll、README.md** 放在 repository 根目錄並提交。不要只上傳 ZIP。
3. 在 repository 的 Settings → Pages 選擇從分支部署，指定 main 分支與根目錄 /，儲存。
4. 等待部署完成，使用 Pages 提供的網站網址。

一般專案網址格式：https://你的帳號.github.io/你的儲存庫名稱/
若使用私人 repository，Pages 的可用性依 GitHub 帳戶方案而定。

## 規則與數位改編
正式卡序與節奏依附帶 PDF 第 10 頁。完成全部九單後，18 人氣達標，最高 36；一般 0 錯 3、1–2 錯 2；加急各加 1。3 錯以上同卡同單型重試一次，通過只得 1，失敗 0。

數位模式每拍最多 1 錯。拍點容許一拍長度的 ±22%，茶葉須在拍點與半拍各一次；黑豬左右間隔不超過 150ms。長按竹筍兩拍，下一拍放開。此容許值為數位版設計，非原規則硬性門檻。主持模式則依真人觀察判定，不用相機／麥克風。

示範與練習提供動作提示；正式演奏僅有拍數與原始卡面。使用 Web Audio 節拍排程，實際裝置、藍牙音訊與瀏覽器仍可能帶來延遲，建議使用內建喇叭或有線耳機。
